## Conventions At-a-Glance
- Routes: kebab-case folders (`wine-lists/`, `price-comparison/`)
- Components: PascalCase files for client components, lowercase for route segments
- Server Components by default; mark `"use client"` only when needed
- Migrations: forward-only, numbered timestamp prefix
- Tests: colocated `*.test.ts` (Vitest) or in `e2e/` (Playwright)
